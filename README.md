## 프로젝트 아이디어

### 돈 버는 기회 포착

1. **펀딩비 트래커** - 펀딩비 ±0.1% 이상일 때 알림 (롱/숏 기회)
2. **김프/역프 알림** - 한국 거래소 vs 해외 거래소 가격 차이
3. **거래소 간 차익** - Binance vs Bybit vs OKX 가격 비교
4. **청산 알림** - 대규모 청산 발생 시 알림 (변동성 기회)
5. **고래 추적** - 대량 입출금 감지

### 자동화 도구

6. **DCA 봇** - 정해진 금액 자동 분할매수
7. **그리드 봇** - 범위 내 자동 매수/매도
8. **리밸런싱 봇** - 포트폴리오 비율 자동 유지
9. **손절/익절 봇** - 조건 충족 시 자동 청산

### 분석 도구

10. **수익률 트래커** - 내 거래 수익률 분석
11. **공포탐욕 지수** - 시장 심리 모니터링
12. **온체인 분석** - 지갑 이동량 추적
