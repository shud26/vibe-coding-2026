## 배운 것들 (What I Learned)

### 기술적인 것
- **API 연동**: REST API, WebSocket, 각 거래소별 다른 응답 형식
- **React Hooks**: useState, useEffect, 의존성 배열의 중요성
- **Web3 개발**: wagmi, viem, 스마트 컨트랙트 연동
- **Mini App**: Farcaster SDK, Account Association, manifest 설정

### 마인드셋
- 안 되는 것도 있다. 그게 개발이다.
- 작은 것부터 시작하면 큰 것도 만들 수 있다.
- 에러 메시지가 친구다.
- VPN은 개발자의 필수품이다 (한국에서 Coinbase 차단됨)
