# Cross-DEX 펀딩비 차익거래 봇

Hyperliquid와 Binance 간 펀딩비 스프레드를 모니터링하고, 차익거래 기회를 탐지합니다.

## 작동 원리

```
펀딩비 차이 발생 시:
┌─────────────┐     ┌─────────────┐
│ Hyperliquid │     │   Binance   │
│  펀딩비 높음  │     │  펀딩비 낮음  │
│    → 숏     │     │    → 롱     │
└─────────────┘     └─────────────┘
        │                 │
        └────── 델타뉴트럴 ──────┘
              (가격 위험 없음)

= 펀딩비 차이만큼 순수익!
```

## 사용법

```bash
# 한 번만 실행 (현재 상황 체크)
python3 funding_arb.py --once

# 30분마다 반복 실행
python3 funding_arb.py

# 1시간마다 반복 실행
python3 funding_arb.py --interval 60

# 기회 발견시에만 알림
python3 funding_arb.py --alert-only

# 백그라운드 실행
nohup python3 -u funding_arb.py > funding_arb.log 2>&1 &
```

## 출력 예시

```
======================================================================
  Cross-DEX 펀딩비 차익거래 기회 | 2026-01-20 13:02:06
======================================================================
코인      Hyperliquid      Binance       스프레드       연수익률 전략
----------------------------------------------------------------------
APT        -0.0001%     -0.0178%    0.0177%      19.4% HL 숏 / BN 롱 ⭐
SEI        -0.0022%     +0.0100%    0.0122%      13.4% BN 숏 / HL 롱 ⭐
BTC        -0.0008%     +0.0094%    0.0102%      11.2% BN 숏 / HL 롱 ⭐
...
```

## 수익률 계산

```
스프레드 0.01% = 연 10.95% 수익률
스프레드 0.02% = 연 21.90% 수익률
스프레드 0.03% = 연 32.85% 수익률
```

계산: `스프레드 × 3회(하루) × 365일`

## 전략 실행 방법

**예시: APT 차익거래**
1. Hyperliquid에서 APT 숏 $1,000 (3배 레버리지)
2. Binance에서 APT 롱 $1,000 (3배 레버리지)
3. 8시간마다 펀딩비 수령
4. 스프레드 줄어들면 양쪽 청산

**필요 자금:**
- Hyperliquid: $333 (3배 기준)
- Binance: $333 (3배 기준)
- 총: $666 → $1,000 포지션

## 주의사항

⚠️ **리스크:**
1. 한쪽 청산 위험 → 레버리지 낮게 유지
2. 펀딩비 급변 → 실시간 모니터링 필요
3. 거래 수수료 → 최소 3-4번 펀딩 수령해야 본전

⚠️ **아직 모니터링 전용:**
- 이 봇은 자동 매매를 하지 않음
- 수동으로 진입/청산 필요
- 추후 자동매매 기능 추가 예정
