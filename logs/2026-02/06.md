## Nado MM Bot 대시보드 제작

tread.fi 스타일로 나만의 MM Bot 대시보드를 만들었다!

### 프로젝트 생성

- 경로: `/Users/hun/mmbot`
- GitHub: https://github.com/shud26/mmbot
- 배포: https://mmbot-mu.vercel.app

### 기술 스택

- **Next.js 16** + TypeScript
- **wagmi v2.12.17** + viem v2.21.19 - 지갑 연결
- **RainbowKit v2.2.0** - 지갑 UI
- **Supabase** - 거래 기록 저장 (nado_trades 테이블)
- **Recharts** - 가격 차트
- **Tailwind CSS** - Glass morphism UI

### 주요 기능

1. **지갑 연결**: RainbowKit + wagmi
2. **ETH 잔액 표시**: useBalance 훅
3. **체인 스위칭**: Ink, Mainnet, Arbitrum, Base, Optimism
4. **가격 차트**: Recharts AreaChart
5. **오더북 시각화**: 매수/매도 벽
6. **텔레그램 알림**: 거래 체결 시 자동 알림
7. **거래 기록**: Supabase 저장

### UI 디자인

- **Glass morphism**: backdrop-filter blur + 반투명 배경
- **Purple gradient**: Nado 브랜딩 (#8b5cf6)
- **다크/라이트 모드**: CSS 변수 테마

### 삽질 포인트

**wagmi 버전 충돌!**
- RainbowKit 2.x는 wagmi ^2.9.0 필요
- wagmi 3.x와 호환 안 됨
- 해결: `wagmi@2.12.17 viem@2.21.19 @rainbow-me/rainbowkit@2.2.0`
