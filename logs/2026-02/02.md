### 배운 것들

1. **변수**: `let` (변경 가능), `const` (고정)
2. **함수**: `function name(params) { return result }`
3. **배열**: `["BTC", "ETH", "SOL"]`, 인덱스 0부터
4. **객체**: `{ name: "Bitcoin", price: 97000 }`
5. **async/await**: API 호출 시 기다리기
6. **try/catch**: 에러 처리

### 미니 프로젝트: 코인 가격 조회기

```javascript
const coins = ["bitcoin", "ethereum", "solana"]

async function checkPrices() {
  try {
    let url = "https://api.coingecko.com/api/v3/simple/price?ids=" + coins.join(",") + "&vs_currencies=usd"
    let res = await fetch(url)
    let data = await res.json()
    for (let coin of coins) {
      console.log(coin + ": $" + data[coin].usd)
    }
  } catch (error) {
    console.log("에러: " + error.message)
  }
}

checkPrices()
```

### C언어 vs JavaScript

| 항목 | C | JavaScript |
|------|---|------------|
| 변수 | `int price = 97000;` | `let price = 97000` |
| 배열 | 크기 고정, 타입 통일 | 크기 무제한, 아무거나 |
| 실행 | 컴파일 필요 | 바로 실행 |
