## nado_grid 8일치 로그 분석 → 버그 발견

### 충격적인 진단 결과
```
라운드트립: 0회 (8일간!)
스톱로스: 70회 (전체 체결의 17%)
서킷브레이커: 11회
pair_placed: 하루 수십~수백 회
```

### 근본 원인
**오더를 너무 자주 재세팅 → 체결 기회 없음 → 한쪽만 체결 → 스톱로스 반복**

드리프트 감지 로직이 포지션이 있어도 재세팅을 하고 있었음.

### 핵심 버그픽스 (grid_bot.py)

```python
# Before: 포지션 무시하고 재세팅
elif pair_center > 0 and strategy.check_drift(current_price, pair_center, product_id):
    place_new_pair(...)

# After: 포지션 있으면 재세팅 스킵
elif pair_center > 0 and strategy.check_drift(current_price, pair_center, product_id):
    position_amt = get_current_position(product_id)
    if abs(position_amt) > 1e-8:
        print(f"Drift 감지 but 포지션 있음 → 재세팅 스킵")
        return
```
