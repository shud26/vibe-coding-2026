# 2026년 6월 셋째 주 — 봇 3종 + 교육 사이트 리빌드

바이브코딩으로 만든 것들을 "끝까지 다듬는" 데 집중한 한 주.

## 🏦 토스 ETF 모멘텀 봇 — 실거래 검증
- **전략**: 가속 듀얼모멘텀(ADM) + 200일선 체제 필터 (약세장 진입 시 안전자산 도피)
- 증권사 OpenAPI 연동 (인증·시세·계좌·주문)
- **지정가 주문으로 첫 실매수 검증** (슬리피지 통제, 안전하게)
- 7개 전략을 가상자본으로 동시 페이퍼 운용 → 수익률 비교 리포트
- 배운 것: 모멘텀 전략엔 별도 손절보다 200일선 필터 + 정기 리밸런싱이 정석. 자금 넣기 전 인프라(전략·추적) 먼저 다듬기.

## 🐦 트위터 다이제스트 봇 — 정보 자동 수집·요약
- **RSSHub를 맥미니 Docker(colima)에 셀프호스트** → X 홈 타임라인을 RSS로
- **로컬 AI(ollama)로 번역 + 인사이트 분석** (트렌드/기회/글감 자동 추출)
- 텔레그램 푸시 + 옵시디언(Obsidian) 자동 저장
- RT(리트윗)·짧은 트윗 노이즈 필터 (피드의 ~38%가 노이즈였음)
- 배운 것: 긴 입력에선 LLM이 형식 지시를 무시 → 입력 축소 + 형식 강제로 해결. 한국어 번역은 모델에 따라 외국어 누출 → 프롬프트로 제어.

## 📚 coindungeon — 크립토 교육 사이트 전면 리빌드
- 게임 컨셉 → **교육 콘텐츠 사이트로 정체성 통일** (검색 유입자가 바로 이해하도록)
- **예약 발행 시스템**: 글을 미래 날짜로 써두면 GitHub Actions가 매일 자동 재배포 → 하루 1편씩 발행
- SEO: sitemap, Article/FAQ 구조화 데이터, 목차·관련글·공유 UX, 구글 서치콘솔 등록
- 가이드 글 작성 (코인 세금·에어드랍·스테이킹 등)
- 배운 것: SEO는 색인(GSC)이 시작점. 콘텐츠가 엔진, 디자인은 포장.
